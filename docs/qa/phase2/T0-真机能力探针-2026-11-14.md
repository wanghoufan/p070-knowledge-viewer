## 2. 对实现的修正

原计划把「Cache Storage + SW Range」作为大视频主路径。本机 MIUI 浏览器上该路径返回的媒体无法播放/seek（dur=0），而 blob URL 可正常 seek；因此正式实现改为：

- **主路径**：视频写入 OPFS，`getFile()` → `blob:` URL 播放；OPFS 不可用时写 IndexedDB Blob → blob URL。
- **回退/研究路径**：Cache Storage + SW Range 保留给桌面/其他 Chromium 浏览器；不作为本机型主路径。
- **不变**：保存后必须做 5s 与 80% 两处 seek 回读，通过才显示「已离线」；浏览器清理后重新导入；媒体不进 Service Worker 壳缓存。

这是一项技术实现修正，不改变任何用户可见需求或 AC。
