## Android 专项最少反例

1. APK 在 Mac 关机、家中路由断开、没有 Tailscale/localhost/域名时无法启动 → FAIL。
2. 实际已保存 ≥500MB 视频不能正常播放或拖动到 80% → FAIL。
3. HTML PPT 通过脚本访问宿主数据/原生插件、主动导航出应用 → FAIL。
4. App 权限被拒绝时崩溃、取消导入后已完成资料消失、升级要卸载重装 → FAIL。
5. Redmi 浏览器历史 PASS 冒充安装到 Android 的独立 APK PASS → FAIL。
6. 发出的链接是应用内私有文件、不可分享的 blob/file 而非真实 HTTP(S) 来源 → FAIL。
7. 未经用户许可附带第三方视频文件发行、加入微信小程序、重做用户批准 UI → FAIL。

## 证据登记要求

每次打勾记录：候选 APK versionCode/versionName、git SHA、产物 SHA-256、debug/release 签名、设备型号/序列号（仅本机记录，不公开）、Android/WebView 版本、网络 Wi-Fi/5G/飞行模式、操作步骤和断言、测试时间、截图/录屏/日志路径。新包 SHA 改变时旧 PASS 变为待复验，不能冒用。

**当前所有 36 项均 NOT_RUN**；历史 PWA 代码/测试保留，等待 Android 工程与 Debug APK 实测。
