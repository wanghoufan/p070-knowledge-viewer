# P070 Android 回归执行清单（T0–T4）

配套工具（均在 `scripts/`，不入公开仓库）：

- `scripts/p070-device.mjs`：用 WebView DevTools 驱动界面并回读状态（点击后一定读回 DOM，不靠盲点）。
- `scripts/p070-picker.mjs`：驱动系统文件选择器（先删旧 dump、只认 `dumped to` 的新鲜结果、按 bounds 中心点击）。
- `tools/build-www.mjs`：`app/` → `www/`。

## 前置

1. 设备锁：`status → resolve → adb -s <serial>`（不写序列号进文档）。
2. 推送测试文件到 `/sdcard/Download/`：`P070-知识清单.json`、`P070-测试视频A-64MB.mp4`、`P070-测试视频B-500MB.mp4`、`P070-课件A-自包含.html`、`P070-课件B-异常.html`，并触发媒体扫描。
3. 确认前台是本应用（`mCurrentFocus`），再发任何点击。

## T0 · 安装与冷启动

| 步骤 | 命令/动作 | 证据 |
|---|---|---|
| 安装 | `adb -s <s> install -r <apk>` | Success + `dumpsys package` 版本 |
| 冷启动 | `am start -n <pkg>/.MainActivity` | `01-boot.png` + `mCurrentFocus` |
| 四 Tab | CDP 读 `.navbutton` 文本 | 文本数组 |
| 无网络权限 | `dumpsys package | grep INTERNET` | 空结果 |
| 飞行模式冷启动 | 开飞行模式 → 强杀 → 冷启动 | 截图 + 可用性 |

## T1 · SAF 导入与持久化

| 步骤 | 动作 | 断言 |
|---|---|---|
| 导入清单 | 头部「＋」→ 选择 JSON → 系统选择器选 `P070-知识清单.json` | 资料数 +3，标题/标签/摘要自动带出 |
| 导入视频 | 详情 → 导入视频 → 选 64MB 片 | 进度条推进；完成后 `mediaInfo.video.bytes == 61689267` |
| 重启保留 | `am force-stop` 后再启动 | 已缓存状态仍在，字节数一致 |
| 重复 ID | 再导入同一清单 | 四选项且不静默覆盖 |
| 取消 | 导入中点取消 | 不产生 `.partial`、不标记已缓存 |

## T2 · 播放与课件

| 步骤 | 断言 |
|---|---|
| 播放 64MB | 可播放、暂停；`currentTime` 递增 |
| seek 5s / 80% | 回调 `seeked`，`|currentTime - target| ≤ 1s`，减少端日志记录 |
| 500MB 片 | 同样通过，且导入不经过 JS（内存不涨） |
| 课件正常 | `SlideActivity` 打开，翻页按钮改变页号，全屏/退出可用 |
| 课件异常 | 外部图片/fetch/跳转被拦，不白屏，无宿主数据泄露 |
| 进课件 | 视频暂停且进度保留，退出后可继续 |

## T3 · 分享/主题/恢复/升级

| 步骤 | 断言 |
|---|---|
| 分享 | Sharesheet 打开，文本仅含 http(s) 原链接；无目标时可复制 |
| 主题三态 | LIGHT/DARK/SYSTEM 全页面一致；SYSTEM 跟随系统；重启保留 |
| 语言 | 中/英切换后四 Tab 与页面文案一致；系统语言不支持时回落 zh-CN |
| 前后台/锁屏 | 切后台、锁屏解锁后清单与进度不丢 |
| 覆盖升级 | 同签名新 versionCode 覆盖安装后资料/进度/分享清单保留（不卸载） |

## T4 · 双品牌与网络场景

| 步骤 | 断言 |
|---|---|
| 红米 + OPPO | 各自安装、冷启动、完整一条讲解链 |
| Wi-Fi → 5G → 飞行模式 | 已导入内容全程可用；原视频外链与网络状态提示正确 |
| Mac 关机/断路由 | 与离线结论一致，核心功能不受影响 |
