## 2. 已批准的实际手机导航（按 HTML V0.3，而不是历史两 Tab 草案）

底部固定 **四个**一级导航，顺序、名称分别为：

1. **资料库**：搜索、全部/中文/英文、主题与标签筛选、打开知识卡片。
2. **已缓存**：集中查看已保存视频及 HTML PPT 的离线状态、占用与清理。
3. **分享清单**：勾选所选资料、复制真实原视频来源链接、系统分享降级。
4. **设置**：深色模式、资料导入、存储管理、可选语言设置。

此为用户已批准 HTML V0.3 的真实结构，**覆盖此前仅「资料库/分享清单」两 Tab 的未冻结草案**。不得在四个 Tab 各自首页重复塞去其他 Tab 的大卡片，也不要再加第五个 Tab。

## 3. 页面可见布局

### 资料库首页
- 左上品牌标识、中英名称，旁边搜索与必要的导入入口；首屏高频任务是筛选资料，不设「欢迎」「菜单宫格」或操作说明页。
- 搜索 → 语言分段（全部 / 中文 / 英文）→ 专题/标签筛选 → 匹克球专题示例视觉 → 单列紧凑视频卡片；卡片左侧缩略图、右侧标题与英文名称/标签/状态。保留用户已认可的信息密度，不自行改成双列网格或舞台大图。
- 每条资料快速加入分享清单，但卡片整面仍能点击详情；各按钮不互相误触。

### 视频详情
- 顶部返回、明确标题与语言标签；视频区域显著。
- **总结必须容易快速看到**，允许保留原型的「概要 / 文稿 / 术语 / 课件」等分段交互。展开文稿不重新初始化播放器，返回后保留观看位置。
- 直接提供「打开 HTML 讲解课件」与来源网址、加入分享清单；不内置 AI 总结或 PPT 生成。

### HTML 讲解
- 单文件自包含 HTML；进入后可全屏、左右翻页、退出回原视频详情。
- HTML 需要隔离执行（\`iframe sandbox\` 或同等级），不得读写主应用数据；导入未知课件失败要有可理解的提示。打开时停止之前的视频声音。
- 演示稿内容由外部 AI 用文稿及用户截图制作，PWA 只导入与展示。

### 已缓存与分享清单
- 「已缓存」按条目显示视频/HTML 是否真正存储以及清理动作，不把模拟缓存冒充已保存。
- 「分享清单」多选，原视频真链接 \`https://...\`，不上传手机 MP4、不分享 \`blob:\` 或 \`file:\` 本地 URL；缺原链接须明显提示并能补录。

### 设置
- 视觉沿用原型的紧凑分组行，不做大号功能入口卡。
- 首次打开**默认浅色**；可切深色并重启保留。若根据现行项目 SOP 继续保留 SYSTEM 三态和英文 UI，必须放在设置的有限空间内，不改变已确认的首页和内容层级。
- 所有按钮须真实可用；模拟数据、调试开关、技术文案不进入最终用户页面。

## 4. 导入/离线/分享的开发合同（这些是此前已经确认的非视觉需求）

- 下载视频、转写、AI 总结、HTML PPT 制作全部在 PWA 之外完成。
- PWA 接收 manifest.json、MP4、HTML；软件外已生成的标题、语言、标签、总结、原始文稿与双语术语无需用户重新填写。
- 真正离线缓存，断网可冷启动、播放并拖动视频、打开课件；若目标国产浏览器能力限制则报真实失败，不假 PASS。
- 支持原视频 YouTube/B 站等原网址分享，朋友访问权限取决于平台网络及作品状态。
- 数据库、登录、在线 AI、下载器、PPT 编辑器均非 V1。

## 5. 技术实现与 UI 冻结的边界

- 已批准 HTML V0.3 是**视觉及交互真源**，而不是生产级后端/PWA 存储实现；可以修复其安全、可靠性和无障碍问题，但不能因为开发方便擅自重新设计布局、另选名称、改变导航结构。
- 允许根据手机浏览器真实情况修复按钮热区、字体溢出、横竖屏、离线状态与安全隔离；不得以「优化」为由重新增加首页、广告、冗长说明、重复导航。
- 手机 PWA 必须经过国产原生浏览器测试（红米/小米和 OPPO）及「添加到桌面」；只通过桌面原型或 Chrome 不算真实验收。
- 用户这次同意的是 UI V0.3，并未授权 Git push、正式对外部署、付费服务、覆盖业务数据；保留项目既有授权与 Human Gate。
