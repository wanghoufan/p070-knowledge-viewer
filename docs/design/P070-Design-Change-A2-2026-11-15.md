# P070｜设计变更记录 A2（资料库紧凑卡片版）

- 日期：2026-11-15
- 触发：另一会话在 `main` 提交 `1fb74c1`（manifest covers / compact cards / portrait player fit）把资料库改成紧凑卡片版；本会话起初按「不重新设计」保留 V0.3，用户看到两张对比图后选择 **A2：采纳紧凑版**。
- 结论：**资料库首页以紧凑卡片版为准**；其余页面（详情、已缓存、分享清单、设置、HTML 课件）仍按 V0.3。

## 1. 相对 V0.3 的可见差异（仅资料库首页）

| 项 | V0.3（旧基线） | A2（现基线） |
|---|---|---|
| 专题头图 | 有：`LEARNING COLLECTION / 匹克球入门 / 6 条资料` 大图块 | 去掉，搜索与筛选之后直接进资料列表 |
| 顶栏 | 品牌 + 深色切换 + 导入「＋」 | 只留品牌（绿标 + 中英名） |
| 卡片状态 | 卡片底部一行文字（✓ 已保存视频 / 内置演示片段 / ○ 待导入视频） | 封面左下角小圆符号：✓ 绿 / ▶ 演示 / ⤓ 待导入 / ⚠ 丢失，文案改为 `title`/`aria-label` |
| 卡片密度 | 一行一卡，卡片较高（约 128px 起） | 卡片更矮，同屏可见 4–5 条 |
| 封面 | CSS 生成的球场/球拍图形 | 支持 `cover` 字段真图；无图时沿用原图形 |
| 语言标签 | 卡内标签行包含「中文/英文」 | 移入封面左上角（中文 / EN） |

## 2. 不变的部分

- 品牌中英文名、绿色主色、四 Tab 顺序与文案、底栏固定与安全区、详情页结构（视频 → 总结 → 文稿 → 术语 → 课件 → 来源）、已缓存/分享清单/设置的信息层级、HTML 课件独立播放。
- 主题三态、中英双语、离线口径与全部 FR/AC 判据不变；导入入口移动到「设置 → 导入学习资料」（顶栏不再有「＋」），深度切换入口保留在详情页与设置页。

## 3. 验收基线更新（对 AC 的影响）

- **AC-21 / AC-28**：资料库首页的对照基线由 V0.3 原型改为本文件 + 现实现截图；其他页面仍对照 V0.3。
- **AC-01 / AC-03**：首屏信息密度按紧凑版判（同屏 4–5 条），「搜索与筛选在资料卡之前」不变。
- **AC-04**：导入入口位置变更后，需重验「文案与跳转一致」（设置页「导入学习资料」→ 系统文件选择器）。
- 其余 AC 判据不变。

## 4. 实现口径

- `app/app.js`：取 `1fb74c1` 的资料库渲染（`statusIcon` / `card` / `library` / `libraryResults` / 紧凑 `bottom`），在此之上保留本会话的 Android 适配（原生导入、媒体 URL、课件、分享、返回键、系统栏、版本号来源）。
- `app/styles.css`：采用 `1fb74c1` 的样式（含 `has-cover` / `st-*` / 紧凑间距），V0.3 的 `.topic-hero` 规则保留但首页不再使用。
- `app/i18n.js`：采用 `1fb74c1` 的版权与隐私告知，并把「浏览器」改为「这台手机」（APK 口径）。

## 5. 回滚

如需回到 V0.3 首页：`git revert` 本次合并提交中的 `app/app.js` 相关段落，或从 `ed8b2be:app/app.js` 取回 `brandHeader/library/libraryResults/card/statusOf`。V0.3 原型文件 `docs/design/prototype/P070-Pocket-Presenter-V0.3-APPROVED.html` 保持不变，不受影响。
