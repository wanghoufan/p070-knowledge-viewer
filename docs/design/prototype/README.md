# P070 随身讲解库 · Phase1 交互原型

> 这是 **Phase1 设计验证原型**，不是正式业务代码，也不代表已进入 Phase2、已通过真机验收或可以发布。
> 目的：让你在手机上/桌面上真实点一遍核心流程，决定设计方向与产品范围是否批准。

## 一、怎么打开（必须用本地 HTTP，不要双击 file://）

```bash
cd "/Users/zzymima0000/Developer/coding/1.Active/070-ing-知识展示器/docs/design/prototype"
python3 -m http.server 8765 --bind 127.0.0.1
```

然后在浏览器打开：<http://127.0.0.1:8765/>

为什么不能双击：原型要真实调用 `fetch()` 把示例 MP4 和讲解稿写进 IndexedDB；浏览器在 `file://` 下会拒绝这类请求，缓存会如实失败（这是浏览器的限制，不是原型缺陷）。

手机预览（同一 Wi-Fi）：把命令改成 `python3 -m http.server 8765 --bind 0.0.0.0`，手机访问 `http://<Mac 局域网 IP>:8765/`。注意：这个地址没有 HTTPS，**不能**用来验收 PWA「添加到桌面」与 Service Worker；那些必须等 Phase2 部署 HTTPS 测试站。

## 二、建议按这个顺序点（约 6 分钟）

1. 启动页 → 进入资料库；看 5 条示例资料和「已离线 / 仅在线」状态。
2. 搜索「双反弹」；切「English」；点标签「热身」；再清除筛选。
3. 顶部深色条是**评审工具**，切 A 卡片 / B 手册 / C 剧场，看同一页的布局、密度、字体、组件是否真的不同。
4. 打开「匹克球热身」：视频可播放、可拖动；总结在首屏；原文稿可展开；双语术语可见。
5. 点「保存到本机」：会真实写入 IndexedDB（约 1.3 MB 示例视频 + 10 KB 讲解稿），状态变为「已离线」；再点「移除本机缓存」可删除。
6. 点「打开讲解」：单文件 HTML 在 `sandbox="allow-scripts"` 的 iframe 里打开；点底部两侧翻页、或直接左右滑动；退出返回详情。
7. 「加入分享清单」→ 底栏「分享清单」→ 复制清单（会复制标题 + 原视频网址，不是本机文件）。
8. 设置里切深色、切 English、刷新页面，确认主题与语言仍保留。
9. 设置里打开「模拟断网」，回资料库看离线状态条；打开「模拟容量不足」，再回详情点保存，看失败提示与重试。
10. 设置里看「本机存储」「清理全部缓存」「重置演示数据」；底部「关于」写明哪些还是模拟项。

## 五、已知限制（评审时请一并看）

1. **设计方向 A/B/C 是评审用开关**，不是产品功能；正式版只会保留你选中的一个方向。
2. 示例视频是测试画面，不是匹克球内容；真实素材需你提供并确认使用权。
3. 原型用 5 条演示数据，真实资料由 Mac 上的 `manifest.json` 导入；ZIP 整包导入 V1 不做。
4. HTML 讲解稿的隔离方案已在桌面 Chrome 验证；国产浏览器 WebView 对 Blob iframe、CSP、全屏的行为仍需真机确认。
5. 原型为省依赖用 IndexedDB Blob 演示缓存；正式产品计划采用 Cache Storage + Service Worker Range 代理（可用面更宽），两者都必须在真机用 ≥500MB 文件复验 seek。
6. 原型没有 Service Worker/Manifest，所以「添加到桌面」与「断网冷启动」在这里演示不了；正式验收必须 HTTPS。
7. `navigator.clipboard` 在无 HTTPS 的局域网地址下可能不可用，原型会自动回退到「手动复制」弹窗；这是有意的降级，不是失败。
8. 导入清单的重复 id 会弹四个选项；示例流程只覆盖单条重复，批量重复按同一策略处理，Phase2 需补测。
9. 原型未做 GBK/非 UTF-8 讲解稿解码与 20MB 以上文件的 blob 分流；正式版按计划实现并在真机复验。
