# 风险与待验证项｜P070 随身讲解库

> 常驻风险位：只记「还没解决、或解决前会咬人」的事。已解决的历史问题进 `docs/history/`，踩坑手法进 `agent.md`。
> 上限 100 行 / 8,192 字节。

## 1. 高影响

### R1 手机端大文件导入/seek 未测
- 影响：核心离线讲解可能失败。
- 触发：MIUI/OPPO 文件选择器、配额、内存峰值、厂商解码器。
- 处置：用真实 64MB/500MB 文件在 MIUI/OPPO 上导入并 seek；未过不得报手机 PASS。桌面 500MB 已通过，仅作机制证据。

### R2 OPPO 真机缺失
- 影响：AC-16/17 无法全绿；不能宣称国产双品牌通过。
- 触发：OPPO PLG110 从设备清单断开。
- 处置：等设备可用后重跑安装、冷启动、播放；不得用 Redmi 结果代替。

### R3 正式 HTTPS 地址缺失
- 影响：朋友打不开、5G 验收与首次发布不成立。
- 触发：只有 `adb reverse` + localhost；无域名/备案。
- 处置：定国内可直连 HTTPS（域名/备案或可用隧道）；5G 实测。

### R4 MIUI SW media Range 路径失败
- 影响：若误用 Cache+SW 主路径，视频无法播放/seek。
- 触发：MIUI Browser 20.30 上 `<video>` 请求经 SW 返回 206 后 duration=0。
- 处置：生产用 OPFS/IDB blob 主路径（已实现）；SW 只做壳缓存；保留 T0 证据。

### R5 浏览器清理 origin 存储
- 影响：视频/文稿/课件一起丢失。
- 触发：磁盘压力、清站点数据、清理软件；`persist()` 返回 false。
- 处置：启动只读自检逐条标「本地副本已丢失」；Mac 主档 + 重新导入；不承诺永久保存。

### R6 导入未知 HTML
- 影响：脚本窃取数据或联网。
- 触发：sandbox 误加 same-origin、CSP 缺失、外链资源。
- 处置：固定 `allow-scripts`、移除源 CSP、注入宿主 CSP、扫描外链、断网复验。

## 2. 中影响

### R7 大文件写入内存峰值
- 影响：低内存手机崩溃。
- 触发：`arrayBuffer()` 整包读、多个 blob URL 未释放。
- 处置：流式写 OPFS、单 video、及时 revoke、size 校验。

### R8 更新与迁移未实测
- 影响：升级丢数据/白屏。
- 触发：SW 版本切换、IDB schema 变更、旧库数据。
- 处置：壳/媒体分离；更新提示不自动刷新；发布前做 V1→V2 升级对账。

### R9 真实素材与版权
- 影响：不能公开演示/分享。
- 触发：5 条授权素材未到位。
- 处置：先用自制/演示素材；首次发布前换真实素材并确认使用权。

### R10 首次发布未签收
- 影响：不能称“可交付”。
- 触发：未 commit/push/部署；未取得用户签收。
- 处置：完成真机与 HTTPS 后，按 Human Gate 找用户签收；签收前矩阵保持 OPEN。
