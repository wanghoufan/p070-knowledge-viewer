## 2. 标签体系（三个维度）

### 2.1 课程归属 → 写入 `topic` 字段（两个课程）

一个条目只有一个 `topic`，**只取两个值**，对应你说的「两个课程」：

`Tennis Fitness`、`小羊老师`

模块细分放进 `tags` 第一项：`体能训练`、`教程概览`、`教程L1`、`教程L2`、`教程Bonus`；`基础技术`、`正手直播`、`发球直播`、`反手截击`、`步伐专题`、`双打专题`。

### 2.2 技术主题 → 写入 `tags` 字段（交叉验证的核心词表）

**两个课程共用同一套词**，这是「打上正手 → 两个课程的正手都出来」的前提：

`正手`、`反手`、`发球`、`截击`、`高压`、`削球`、`放小球`、`接发球`、`步伐`、`双打`、`球感`、`力量`、`核心`、`柔韧`、`敏捷`、`速度`、`平衡`、`恢复`、`热身`、`耐力`

> 口径说明：`凌空` 归入 `截击`；`前脚/后撤步/迎前步/找球/站位` 归入 `步伐`；`弹力带/自重/爆发` 归入 `力量`；`拉伸/瑜伽` 归入 `柔韧`。

### 2.3 内容性质 → 写入 `tags` 字段（顺序练习的核心词表）

`练习`、`讲解`、`直播课`、`介绍`

配合 `L1` / `L2` 级别标签，以及导入时按序号设置的 `order` 字段。

## 3. 三个目标的达成方式

| 目标 | 做法 | 当前系统是否支持 |
|---|---|---|
| ① 课程打标签 | 每条的 `topic` = 课程模块，筛选栏直接出现课程按钮 | ✅ 支持（`tagList()` 读取 topic） |
| ② 交叉验证 | 两个课程的正手条目都打 `tags:['正手']`，点「正手」即跨课程汇总 | ⚠️ 筛选逻辑支持，但**筛选栏不显示自定义 tags**（见 §4） |
| ③ 顺序练习 | 练习条目打 `tags:['练习']` + 技术 tag，`order` 按课程内序号 | ⚠️ 同 ②，按钮不可见；排序已支持 |

## 4. 必须改的一行代码（待你决定，本轮未改）

`app.js` 的 `tagList()` 只收集 `base + topic`：

```js
const extra = Array.from(new Set(all().map(x => x.topic).filter(t => t && !base.includes(t))));
```

结果：`tags` 里的「正手」「练习」**不会出现在筛选栏**，用户点不到，交叉验证与顺序练习无从触发。建议改为同时收集 tags：

```js
const extra = Array.from(new Set(all().flatMap(x => [x.topic, ...(x.tags || [])]).filter(t => t && !base.includes(t))));
```

改完筛选栏会出现「正手/反手/练习/讲解/…」按钮。筛选逻辑 `x.tags.includes(state.tag) || x.topic === state.tag` 无需改动。
注意：筛选是**单选**，不能同时点「正手 + 练习」。若要「正手的练习」这种交叉，需再加多选支持——本方案先按单选设计，靠「练习」+ 序号顺序满足顺序练习。
