## 1. Product Goal / 用户与范围

提供一款**本人在户外完全离线使用的安卓随身讲解 APK**：Mac 上事先准备匹克球等专题的视频、中文或英文文稿、AI 整理的相应语言摘要、双语术语和带图片的 HTML PPT；手机导入后依靠本机存储进行搜索、阅读、播放、现场全屏讲解，并能批量向外国朋友分享视频平台原始观看链接。

V1 只做 Android；**不做 PWA 正式发布、不做微信小程序、不做 iOS**。不增加在线视频下载、转写、AI 摘要/PPT 生成、远程 Mac 服务、云数据库、账号登录、支付、社交平台或多人同步。

不要让开发者再提问 UI 名称、颜色、Tab 数或 HTML 主格式：已确认「随身讲解库 / Pocket Presenter」、方案 A 绿色紧凑界面、四 Tab（资料库 / 已缓存 / 分享清单 / 设置），默认 LIGHT + 可切深色，沿用项目中英 UI 与术语显示要求。

## 4. 安卓技术方案（已由产品顾问决策，不移交用户二次选型）

**主路线：Capacitor 将已有 `app/` 迁移为仅安卓的 Web UI APK，针对大文件与不可信 HTML 课件补 Android 原生能力。** 能复用的 CSS、JS、数据/筛选/文稿/主题/分享逻辑不重写；新建 Android 原生工程并锁定实际可构建的 SDK/Gradle/Capacitor 依赖。全 Kotlin Compose 重绘不是默认任务，除非经真实性能与安全证据证明 Capacitor 桥接无法满足 P0。

系统能力合同：

1. **应用离线启动**：页面和必要依赖全部随 APK 打入，启动不可请求外部 HTTPS、`localhost`、家中 Mac mini、adb reverse、Tailscale、Docker、开发服务器。正式 APK 不靠 Service Worker 或 PWA Manifest 工作。
2. **本地文件导入**：安卓 SAF `ACTION_OPEN_DOCUMENT` 选 manifest/MP4/HTML；取得相应临时/持久授权，逐块复制到 Android 应用专属**持久**数据目录，写入临时文件、比对大小/可选校验后才提交；**禁止整条视频经过 JavaScript base64 或一次性 ArrayBuffer**。
3. **媒体**：优先评测复用已有视频控件对应的 APK 安全本地 URI 播放；若 500MB/1GB 真机 seek、进度恢复或后台播放未过，接 Media3/ExoPlayer 原生播放模块，保持视频详情页视觉位置与用户操作。不能用桌面 Chrome 成功替代手机 APK。
4. **HTML 课件安全**：单文件、自包含，无外部资源；用**独立且未暴露 Capacitor 原生桥的受限 WebView**承载，限制网络、文件访问、跳转与宿主 API；提供全屏、翻页、退出，进入时暂停视频。不得仅凭网页中的 iframe sandbox 断言原生桥安全。
5. **元数据与状态**：沿用 `manifest.json`，标题/标签/原文稿/术语等按条目关联；本地 SQLite 或经过验证的 WebView IndexedDB 均可，但数据必须在重启/覆盖安装后保留，与私有媒体文件状态一致。
6. **分享**：Android 原生 Sharesheet 或复制文本；只分享合法原视频网页 URL；本机源文件不自动发给朋友。
7. **升级与迁移**：稳定 Android 包名与版本编号；Debug 和 Release 方案分离，Release 签名安全保存；覆盖安装数据保留。原 PWA 和新 APK 是不同存储主体，**不承诺将浏览器 OPFS/IndexedDB 自动搬进 APK**；提供 Mac 主档重新导入的操作路径。
8. **Android 权限**：只请求必要系统选择器访问，不索取全盘文件权限。安卓返回、前后台、锁屏、横竖屏安全区与强制暗色适配要真机验证。

## 6. 数据、版权与备份

- 应用不含未获公开许可的第三方视频，所有使用的视频由用户依法获取/授权后导入，发布库不得自动包含其媒体/个人笔记。
- 用户应在 Mac 保存原始知识包和视频；APK 内部文件是手机副本，**卸载 APK 会导致应用私有数据删除**，清理/升级前需警示并保留重导路径。
- 清理单条媒体只影响选中资料；「清空」有二次确认，不能删除 Mac 主档。
- 外链可能受视频平台、地区与网络影响：无网络仍可复制 URL，不能承诺朋友在任意地区打开 B站/YouTube。
- 不建立新数据库/云同步服务，不在 APK 存放第三方 API Key。

## 7. 当前真实进度与版本变更影响

截至 2026-11-15 本地 P070 的 `app/` 已实现**静态 PWA**，包含四 Tab、筛选、存储、HTML 课件、复制分享等。历史证据记录桌面自动化 32/32 PASS、500MB 桌面存储/seek、红米浏览器部分冷启动测试，**只作为复用依据，全部不可当作 APK 真机 PASS**。项目 Git 当前 `main...origin/main` 工作树无未提交状态；云端未核实本机 Android SDK/ADB/最终 APK。

转换将改变 APK 构建、数据目录、媒体导入与播放、HTML 安全、版本更新/安装测试；其他 FR 与 UI 均继承旧版。现行 `docs/plan/P070-Android-APK-Execution-V1.2.md` 是 Phase2 的执行清单，不增加另一份 FR/AC 真源。

## 10. 开发顺序与完成定义

- P0：旧 PWA 代码与获批 V0.3 对照，建立 Capacitor 仅安卓工程，**先出可以在真机打开的 Debug APK**；检查应用是否完全脱离开发服务及 WebView 是否正确运行 UI。
- P1：系统 SAF + 原生持久存储迁移；完成元数据/媒体导入、真实校验与目录/权限拒绝/异常恢复；性能及可靠性测试。
- P2：视频播放/大文件 seek、HTML 课件独立安全 WebView、原生返回与分享；全部功能回归并修复。
- P3：真实 5G/飞行模式、Mac 关机、后台锁屏、重启恢复、横竖屏、覆盖升级、数据保留和异常路径。
- P4：指定 Redmi 与 OPPO 真机、真实素材、系统权限与签名一致性、完成适用的中央回归清单，保存视频和测试证据。
- P5：经用户批准后生成并分发签名 Release APK；记录应用 ID、versionName/versionCode、commit/工作树、APK SHA-256、签名类型、真实设备和验收证据；**未签收不宣称正式交付**。

触发任何无法消除的 P0 平台限制时由开发者先尝试既定原生替代：Android WebView 播放失败→Media3；WebView 课件隔离失败→独立受限 WebView；大文件 JS 传输失败→原生流式。除范围/安全性质变化、付费、不可逆操作和首发授权，不应再要求用户重新选技术或 UI。
