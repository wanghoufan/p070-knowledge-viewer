## 1. Product Goal

做一个**轻量、离线优先的随身讲解库 PWA**：用户在 Mac 上完成视频获取（须有合法使用权）、转写、AI 总结与 HTML 讲解稿制作；手机只负责**导入、整理、筛选、现场播放与分享原视频链接**。真正断网时，不依赖家里 Mac、Wi-Fi、Tailscale 或在线 AI，也能打开资料、播放已缓存视频、读总结、翻看讲解稿。

首版以匹克球专题验证（热身、规则、等级、技巧、英语术语），但架构不写死为匹克球专用。

## 2. Target Users

- 主用户：需要在球局、聚会、课堂、旅行等现场做 5–20 分钟讲解的人；本人已在电脑上准备好视频、总结与讲解稿。
- 次用户：拿到分享清单的朋友——只收到**原视频网页链接**，不需要安装任何东西。
- 非目标用户：想在本 App 内下载视频、自动转写、自动生成 PPT 的人；需要多人协作、账号体系或云同步的人。

## 3. Problem

1. 现场网络不可靠：家里 Wi-Fi、代理、云端 AI 在球场/活动场地经常不可用。
2. 资料散落：视频在相册、总结在文档、讲解稿在另一个 HTML 文件，现场来回切换，容易讲断。
3. 分享错东西：直接把手机里的视频文件发出去，既大又涉及版权；朋友真正需要的是原视频网址。
4. 现有工具太重：笔记软件不擅长视频 + 幻灯片的现场切换，PPT 工具又需要联网/账号。

## 4. Core Value

**一次导入，现场离线讲完；分享只发原视频链接。** 不生产内容，只把已经做好的内容整理成可离线使用的讲解包。

## 8. 核心任务与 MVP 边界（Gate A）

- 核心任务（一句话）：**在手机上手边没有网络时，打开一条已缓存的讲解资料，边放视频边翻讲解稿。**
- 高频功能：搜索/语言/标签筛选、打开视频、看总结、打开讲解稿、加入分享清单。
- MVP 必含：
  1. 资料库 + 搜索 + 语言/专题/标签筛选（对应核心任务的前置定位）。
  2. 视频详情：播放器、总结、文稿、术语、来源。
  3. 单文件 HTML 讲解稿隔离播放。
  4. 视频/讲解稿真实落盘与状态显示。
  5. manifest 导入与媒体关联。
  6. 分享清单（只发原链接）。
  7. 主题三态 + 中英 UI + 设置持久化。
- 可延后／可隐藏／可取消清单：
  - 可延后：ZIP 整包导入、系统分享面板增强、封面自定义、批量关联、讲解稿页数识别。
  - 可隐藏：导入记录明细、缓存逐条字节数（设置内二级展开）。
  - 可取消：示例数据重置入口（正式版删除）、演示用「模拟断网/模拟容量不足」（正式版删除），旧 A/B/C 评审切换不进入生产版。
  - 不删减：空态、删除确认、失败重试、离线状态、版权与来源提示——这些是必要恢复与告知，不属于冗余。
- 交付形式判断：**PWA**。理由：单用户、本地数据、无后端；需要「添加到桌面 + 离线 + 可更新」，PWA 最轻；不做 APK 可避免签名、商店与安装门槛。原生 App 的大文件能力更强，但当前需求不值得为此增加分发成本。
- 治理强度分级（逐项）：
  - 安全风险＝**中**（导入不可信 HTML、版权与来源；无健康/资金数据）
  - 设备能力＝**中**（大文件存储、视频 seek、国产浏览器差异、PWA 安装）
  - 数据敏感度＝**低**（本地学习资料与公开视频链接；无账号、无隐私采集）
  - 异常恢复＝**高**（容量不足、缓存被清、更新迁移、断网，资料可重建但必须可识别）
  - 用户操作复杂度＝**中**（导入→关联→缓存→讲解是多步流程，但单线程、可重试）
  - 判定级别＝**标准**（不降为轻量；安全告知、隐私与授权、数据正确性、异常恢复、真机可用性五类验收一条不减）

## 9. APP 基础能力声明

- 适用性：**是**，面向用户交付的手机 PWA（不是原生 APK）。
- 平台与技术栈：Android 小米/红米自带浏览器、OPPO 自带浏览器为主验收；桌面 Chrome 仅开发辅助。技术栈：原生 HTML + CSS + ES Modules + Service Worker，无框架、无构建链（见 §14）。
- 主题：`LIGHT` / `DARK` / `SYSTEM` 三态；**默认 `LIGHT`（用户明确要求，覆盖 SOP 默认 `SYSTEM`）**；沉浸式讲解页遵守用户所选主题，不强制另一态。
- 语言：初始支持 `zh-CN` ＋ `en`；设置项 `FOLLOW_SYSTEM`（默认）/ 简体中文 / English；系统语言不支持时**回退 `zh-CN`**。内容语言（视频是中文还是英文）与 UI 语言是两个独立维度。
- 设置持久化：主题、语言、分享清单、播放位置、导入记录重启保留；切换主题/语言不丢业务状态、进度与当前操作。
- 可扩展架构（硬性）：文案走资源字典 + `data-i18n`，业务代码不写 `if 中文 else 英文`；未来加 ru/ko/th 只增资源与必要适配，不改核心业务架构；本版不制作这些翻译。
- 语音能力：**否**，非语音类 APP。
- 技术栈复用判定（先查项目已有依赖：本项目无业务代码、无框架、无依赖）：
  - 主题＝`BUILD`（约 40 个 CSS 语义 Token；不引入 UI 框架）
  - 多语言＝`BUILD`（轻量资源字典，约 150 键；不引入 i18next 与构建链）
  - 理由：项目是单页轻应用，引入框架/构建链的复杂度大于收益；正式库版本/License 由 Phase2 Reuse Audit 按既定顺序复核。
- 覆盖记录：**主题默认值由 SOP 的 `SYSTEM` 改为 `LIGHT`，依据用户 2026-11-14 明确要求**；其余默认要求不裁剪。

## 13. Technical Approach

### 13.1 总体

- 纯静态 PWA：`index.html` + `styles.css` + `app.js`（ES Modules）+ `db.js` + `slides.js` + `i18n.js` + `sw.js` + `manifest.webmanifest`。无框架、无构建链，部署即静态文件。
- 状态：主题/语言/分享清单/播放位置用 localStorage；资料元数据、缓存媒体、导入记录用 IndexedDB；大视频优先 OPFS。
- 应用壳与用户数据分离：Service Worker 负责两件事——①缓存应用壳（HTML/CSS/JS/图标）；②拦截 `/__p070_media/<id>` 并按 `Range` 返回 206（读 Cache Storage/OPFS）。壳缓存带版本、媒体缓存 `p070-media` 不带版本；升级只换壳，不动 `items`/`media` 数据。

### 13.2 存储与播放（核心风险）

- 元数据：IndexedDB `items`（id/title/topic/language/tags/summary/transcript/terms/source_url/slides 等）。
- 大视频主路径：**Cache Storage（主）+ Service Worker Range 代理**。视频以合成 URL（`/__p070_media/<id>.mp4`）写入 Cache Storage；`<video src>` 指向同一 URL，SW 拦截请求、按 `Range` 返回 `206 Partial Content`。这条路径只要求 SW 可用，不要求 OPFS，兼容面最宽。
- OPFS 作为可选加速：支持时用 `getFile()` 提供随机读取，仍由 SW 统一出 Range；不支持则完全走 Cache Storage。
- blob URL 仅作为 SW 不可用时的降级：`getFile()`/IDB Blob → `URL.createObjectURL()`；UI 标注「可播放，但可能占用较多内存」，且必须真机验证。
- **「已离线」必须先通过一次真实 seek 回读**：设置 5 秒与 80% 时长两处，读回位置误差在 1 秒内才算 PASS；`loadedmetadata` 成功不等于可 seek。没有 Range 时浏览器会触发 `seeked` 却把位置重置回 0（已实测），不能只看事件。
- 内存硬约束：全程只保留一个 `<video>`；切换条目必须 `video.src=''` + `URL.revokeObjectURL()`；禁止把整个 MP4 读成 `ArrayBuffer`（校验用 size + 首尾 64KB 抽样，不做整文件一次性哈希）。
- 配额：写入前 `navigator.storage.estimate()` 预检（剩余 < 文件大小 × 1.15 先提示）；`persist()` 只作为尽力而为——本机实测返回 `false`，Chromium 会静默授予或拒绝且不弹窗，**不能把「已离线」建立在 persist 成功上**。
- 容量基线：单条视频目标 ≤1.5GB，资料库总缓存目标 ≤4GB；超过时提示而不是静默失败。浏览器可能按 origin 整体清理（IndexedDB/Cache/OPFS 一起没），所以「原片在 Mac 有主档、手机缓存可重建」必须写进 UI 文案。

> **T0 实测修正（2026-11-14，Redmi Note 12T Pro / MIUI Browser 20.30）**：本机型上「Cache Storage + SW Range」返回的媒体无法播放/seek（duration=0、seekable=[0,0]），而 OPFS/IndexedDB Blob → `blob:` URL 的 seek 正常。因此生产实现改为 **OPFS → blob 为主路径，IndexedDB Blob 为降级，Cache+SW Range 保留为桌面/兼容回退**；「保存后 5s 与 80% 两处 seek 回读」的判据不变。详见 `docs/qa/phase2/T0-真机能力探针-2026-11-14.md`。

### 13.3 HTML 讲解稿隔离

- `iframe sandbox="allow-scripts"`（**不带** `allow-same-origin`、`allow-top-navigation`、`allow-popups`），`referrerpolicy="no-referrer"`，并加 `allowfullscreen`；iframe 获得不透明来源，读不到主应用存储（实测 origin=null，localStorage/IDB/cookie 全部 SecurityError）。
- 导入时注入三层硬化：
  1. CSP：`default-src 'none'`，仅允许 `data:`/`blob:` 的图片、媒体、字体与内联样式/脚本（隔离环境允许 `unsafe-eval`，因不透明来源读不到主应用数据），`connect-src 'none'`，阻断外部请求；meta 必须放在 `<head>` 最前（meta CSP 只约束其后的请求）；
  2. 删除 `<base href>`（会把相对路径改到远端），检测 `<meta charset>`，GBK 文件用 `TextDecoder('gbk')` 重解；
  3. Bridge：监听 `postMessage` 的上一页/下一页，向文档派发 `ArrowLeft/ArrowRight`；按 Esc 通知宿主退出；加载后回报 `ready`。
- 自包含检查：扫描 `src=`/`href=`/`url(` 中的 `http(s)` 外链、`file://`、UNC 路径；命中则标「可能依赖网络」，仍可打开但 QA 必须断网复验；`<a href>` 外链允许但加 `target="_blank" rel="noopener"`。
- 全屏：宿主用满屏 overlay 承载 iframe；「全屏」按钮放在讲解顶栏，对 overlay 调 `requestFullscreen()`（不是对跨源 iframe 调用），同时给 iframe 加 `allowfullscreen` 作为双保险；退出入口常驻，任何课件都能退出。
- 返回键：进入讲解时 `history.pushState`，`popstate` 先退出讲解而不是离开应用；旧 Android WebView 不保证支持，Phase2 真机确认。
- Bridge 3 秒未握手：保留父层上/下翻页条与退出入口，并提示「若翻页无效，请在课件内左右滑动」；**不在 iframe 上叠透明点击区**（父层要收点击必然截获该区域指针，技术上不是兜底）。导入时移除课件自带 CSP 再注入宿主 bridge，避免 bridge 被上游 CSP 挡住。
- 大文件：单文件 HTML 超过 20MB 时用 `blob:` URL 投喂，不用 `srcdoc`，避免整串常驻 DOM。

### 13.4 数据与导入

- manifest 推荐格式：
  ```json
  {
    "version": "1.0",
    "items": [
      {
        "id": "warmup-01",
        "title": "匹克球热身：上场前 8 分钟",
        "topic": "匹克球",
        "language": "zh",
        "tags": ["热身", "零基础"],
        "summary": "……",
        "transcript": "……",
        "terms": [{ "zh": "截击", "en": "Volley" }],
        "source_url": "https://www.bilibili.com/video/...",
        "video_file": "warmup.mp4",
        "slides_file": "warmup.html"
      }
    ]
  }
  ```
- V1 导入路径：选 manifest → 逐条关联本机 MP4/HTML（浏览器不允许网页静默读取任意本地路径，必须用户点选）。ZIP 整包导入延后。
- 重复 id：四选项——保留原素材只更新文字 / 替换视频与讲解稿 / 跳过重复 / 取消整次导入；默认不预选，禁止静默覆盖。
- 校验：id/title 必填；source_url 仅接受 http/https；terms 结构校验；缺失字段用空值并显式提示，不编造。
- 写入作业状态单独存 `pendingImports`（IndexedDB），切后台/中断后可继续或清理，不依赖内存变量；界面提示「保持屏幕常亮、不要切走」，支持时申请 Wake Lock 并在退出释放（国产浏览器支持情况未测）。

### 13.5 分享

- 分享文本＝每条「标题 + 原视频网址」，空行分隔。
- 只允许 http/https；缺链接的条目在清单里标黄并跳过，绝不把 `blob:`、`file://`、本机路径写进分享文本。
- 支持 `navigator.share` 时调用系统分享；不支持时复制到剪贴板；剪贴板不可用（无 HTTPS/权限拒绝）时弹「手动复制」文本框。

### 13.6 PWA 与更新

- `manifest.webmanifest`：中文 name/short_name 使用「随身讲解库」，英文显示使用「Pocket Presenter」；`start_url`/`scope`/`display:standalone`/图标/主题色。
- Service Worker：壳缓存版本化（`p070-shell-vN`），媒体缓存独立命名（`p070-media`）且**任何升级都不删**；安装时只预缓存壳，`skipWaiting` 不自动接管，等用户点「更新」；旧缓存清理只清 `p070-shell-*`。
- 数据迁移：IndexedDB `version` 升级走 `onupgradeneeded`，只加不改；升级前写迁移标记，失败保留旧库并提示导出/重导。
- 更新提示：底部条「有新版本，更新后资料不会丢」，用户点更新才 `skipWaiting` + reload；不自动刷新。

### 13.7 部署与外部依赖（Phase2 真实门槛）

- **HTTPS 是硬前提**：同一页面在 `http://192.168.x.x` 下 `isSecureContext=false`、`navigator.serviceWorker` 不存在、OPFS 与 `crypto.subtle` 均无；只有 `127.0.0.1` 全可用（已实测）。手机端「离线/PWA」验收**不能**用局域网 HTTP，只能看样式。
- 开发期：本地 `localhost` 全功能；真机看样式可用局域网 HTTP（明确标注「仅样式，不验 PWA」）；需要真机功能时用 HTTPS 隧道（Cloudflare Tunnel/ngrok，需先实测本机可用性）。
- 真机验收期：必须用**中国大陆手机 5G 能直连**的地址。候选与已知限制：
  - **GitHub Pages**：本机宽带直连 200，但手机 5G 未测；不支持自定义响应头（CSP 只能靠 meta）；可作临时预览，不能直接当终验站。
  - **Netlify**：本机可达；项目规则要求先 draft 后 prod、生产按次计费、需用户明确同意；仍须 5G 实测。
  - **Vercel**：本机 `*.vercel.app` DNS/连接异常（可能只是该域名不存在，不能断言被墙）；本计划不作候选。
  - **腾讯 CloudBase 静态托管**：新环境默认域名已对非导航请求加 `Content-Disposition: attachment`（官方公告），JS/CSS/manifest/SW 会被强制下载，**不能直接用于 PWA**；必须绑自定义域名 → 备案。
  - **腾讯 EdgeOne Pages**：海外加速区不要求备案；大陆/全球（含大陆）加速需备案（官方页面正文本次未取回，标丙级，需再核）。
  - **大陆对象存储 + CDN（OSS/COS）**：最稳但备案与成本最重，V1 不必。
- 结论：**临时预览可用海外静态托管；正式真机验收必须用大陆 5G 能直连的地址**。备案是时间成本项（主体 + 域名实名 + 接入商审核），需在 Phase2 D 阶段之前排期，不能上线前一天才想起。
- 其他外部依赖：GitHub 远端当前未创建（README 称尚无远端）；是否建、公开/私有、何时 push 由用户在 Human Gate 后决定。本轮不 push、不部署。

## 14. Data / API

- 无后端、无外部 API、无 Key、无账号。
- 本地数据表：
  - `items`：id, title, topic, language, tags[], summary, transcript, terms[{zh,en}], source_url, has_video, has_slides, created_at, updated_at。
  - `media`：id, kind(video|slides), opfs_path 或 blob, bytes, cached_at, checksum(可选)。
  - `settings`（localStorage）：theme, language, share_ids[], playback_pos{}, schema_version。
- 数据权威源：Mac 上的原始资料为主档；手机缓存是可重建副本。清除缓存不丢主档。

## 15. Key Assumptions

1. 目标浏览器基于 Chromium，支持 IndexedDB 与 Service Worker；OPFS 是否可用需真机探针（不支持则走 Cache Storage + SW Range，不依赖 OPFS）。
2. 桌面 Chrome 上 SW Range 与 blob URL 都能 seek；MIUI 真机实测 SW media 路径失败、blob 路径可用，故生产以 OPFS/IDB blob 为主。桌面 500MB 真文件已实测（5s/80% 均通过）；手机端 500MB 仍 NOT_RUN。
3. `navigator.storage.persist()` 不可依赖：本机实测返回 `false`，Chromium 静默授予/拒绝；浏览器可能按 origin 整体清理，所以「重新导入」是一级恢复路径。
4. 国产自带浏览器可能只创建快捷方式而非完整 PWA；「添加到桌面」与「离线可用」分开验收；厂商文档缺失，必须真机探针。
5. 单文件 HTML 讲解稿是主要形态；多文件 ZIP 在 V1 不做。
6. 用户能提供 5 条有合法使用权的视频与自制/授权讲解稿；真实素材到位前用示例数据开发。
7. 现场使用以手机竖屏为主，讲解时可横屏；两种方向都要可用。
8. 资料规模首版 ≤50 条，单条视频 ≤1.5GB；搜索用客户端子串匹配即可，不需要全文索引。
9. 手机端 PWA 验收必须有 HTTPS；局域网 HTTP 只能看样式，不能验 Service Worker/OPFS/离线。
10. **视频下载、转写、AI 总结、PPT 制作、视频文件整理与长期保存全部在电脑端完成；手机端只负责播放已缓存/已准备好的视频、阅读文稿与打开 HTML 课件，不承担大文件导入/转码/处理性能验收。** 手机端如需关联文件，只是一次性“选择已准备文件”，不属于处理链。

## 16. Competitor / Research Summary

- **Reveal.js / Slidev**：成熟的 HTML 演示工具，可导出静态页面；适合作为「软件外制作」工具。风险是默认模板可能引用 CDN 字体/脚本，导入前必须做成真正自包含单文件。P070 不内嵌编辑器。
- **Anki / 本地知识库**：证明「离线优先 + 本地媒体」可行；但它们的强项是记忆卡片，不是视频 + 幻灯片现场切换，P070 不重复其卡片系统。
- **笔记类 PWA（Notion/Obsidian 移动端）**：离线能力受产品策略限制，且不适合大视频；P070 的差异是「只管讲解现场，不做笔记编辑」。
- **浏览器存储能力**：IndexedDB/OPFS/Cache Storage 均为标准 Web API；大文件配额与持久化授权因浏览器而异，必须实测，不能凭文档承诺。
- 详细来源、证据等级与未核实项见 `docs/review/P070-技术可行性调研-2026-11-14.md`；模板复用依据见 `docs/design/UX-CONTRACT-P070-V1.0.md`（TPL-18/21/22/24/25）。

## 17. Risks

|---|---|---|---|
| 国产浏览器不支持 SW / 大视频配额低 | 离线播放不成立 | 中 | Phase2 首日探针；主路径不依赖 OPFS（Cache + SW Range）；SW 也没有时降级 blob 并标内存风险；仍不行则如实报 BLOCKED 并提替代（每次选择本地文件） |

| 无 HTTPS 或使用 CloudBase 默认域名 | PWA 装不上/资源被强制下载 | 高 | 真机验收前先解决 HTTPS；CloudBase 必须绑自定义域名；备案提前排期；不以海外平台文档当 5G 可达 |
